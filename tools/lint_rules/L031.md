# L031: Literal too large for its variable

| Property | Value |
| --- | --- |
| Severity | error |
| Fixable | no |
| Source | [Error: Integer overflow](../../skills/micros-isl-language/isl-reference/reference/errors.md#integer-overflow), [Error: String overflow](../../skills/micros-isl-language/isl-reference/reference/errors.md#string-overflow), [Error: Decimal overflow](../../skills/micros-isl-language/isl-reference/reference/errors.md#decimal-overflow), [Error: Format too long](../../skills/micros-isl-language/isl-reference/reference/errors.md#format-too-long) |

A literal assigned to (or used to initialise) a variable that cannot hold it: more digits than `N<n>` or `$<n>`, more characters than `A<n>`, or `format` text longer than the target.

## Why

Assigning a value that exceeds the declared size raises an overflow error at run time.

## Bad

```isl
event init
  var n : N3
  n = 12345
endevent
```

## Good

```isl
event init
  var n : N3
  n = 123
endevent
```

## Limits

Only literals and variables with a numeric size are checked.
