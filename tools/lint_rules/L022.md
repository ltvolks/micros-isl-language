# L022: System variable misuse

| Property | Value |
| --- | --- |
| Severity | error / warning |
| Fixable | no |
| Source | [Guide ch. 6: Guidelines for Specifying System Variables](../../skills/micros-isl-language/isl-reference/guide/chapter-6.md#guidelines-for-specifying-system-variables), [Error: Unknown system variable](../../skills/micros-isl-language/isl-reference/reference/errors.md#unknown-system-variable), [Error: Sys var not assignable](../../skills/micros-isl-language/isl-reference/reference/errors.md#sys-var-not-assignable), [Error: Bad sys var index](../../skills/micros-isl-language/isl-reference/reference/errors.md#bad-sys-var-index) |

An unknown `@name` (warning), assignment to a read-only system variable, an `@SI` index outside 1-16, `@SI` with no index, or `@Warnings_Are_Fatal` set after the first event or sub.

## Why

The reference marks each system variable read-only or not. Guide chapter 6 gives the `@SI` range as 1-8 while the error catalogue says 1-16, so indexes 9-16 are a warning.

## Bad

```isl
event inq : 1 // x
  @cknum = 1
  display 1, 1, @RVVC
endevent
```

## Good

```isl
event inq : 1 // x
  @strict_args = 1
  display 1, 1, @SI[3]
endevent
```

## Limits

Print directives that are not entries in the reference (`@Header`, `@Ordr#`) are accepted.
