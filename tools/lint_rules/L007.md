# L007: Waiting for a reply without timeout handling

| Property | Value |
| --- | --- |
| Severity | warning |
| Fixable | no |
| Source | [Command: WaitForRxMsg](../../skills/micros-isl-language/isl-reference/reference/commands.md#waitforrxmsg), [Command: Use[ISL/STD]TimeOuts](../../skills/micros-isl-language/isl-reference/reference/commands.md#useislstdtimeouts) |

`waitforrxmsg` or `getrxmsg` is used but the file neither calls `UseISLTimeOuts` nor defines `event rxmsg : _timeout`.

## Why

Without timeout handling a lost reply leaves the operator waiting on the standard timeout and the script without a chance to recover.

## Bad

```isl
event inq : 1 // ask
  txmsg "a"
  waitforrxmsg
endevent
```

## Good

```isl
useisltimeouts
event inq : 1 // ask
  txmsg "a"
  waitforrxmsg
endevent
```
