# L011: Malformed variable declaration

| Property | Value |
| --- | --- |
| Severity | error |
| Fixable | no |
| Source | [Guide ch. 4: Data Types](../../skills/micros-isl-language/isl-reference/guide/chapter-4.md#data-types), [Command: Var](../../skills/micros-isl-language/isl-reference/reference/commands.md#var), [Error: Exceeded max array or variable size](../../skills/micros-isl-language/isl-reference/reference/errors.md#exceeded-max-array-or-variable-size) |

A `var` with no `: type`, a type that is not `N<digits>`, `$<digits>`, `A<chars>` or `key`, whitespace inside the specifier (`N 5`), a size of 0, a `key` with a size, or a size or array size above 32768.

## Why

"When a variable is declared using the Var command, its data type and size must also be declared." A size may be a number or an expression in parentheses (`A(len)`).

## Bad

```isl
event init
  var count
  var name : q20
  var flag : n 5
  var k : key5
endevent
```

## Good

```isl
event init
  var count : N3
  var name : A20
  var k : key
  var width : A(count)
endevent
```

## Limits

Sizes given as expressions are not evaluated.
