# L036: Input needs a variable

| Property | Value |
| --- | --- |
| Severity | error |
| Fixable | no |
| Source | [Command: Input](../../skills/micros-isl-language/isl-reference/reference/commands.md#input), [Error: Not a variable](../../skills/micros-isl-language/isl-reference/reference/errors.md#not-a-variable) |

The first argument of `input` or `inputkey` is a literal.

## Why

Input stores what the operator types, so it needs a variable to store it in.

## Bad

```isl
event inq : 1 // ask
  input 123, "Enter value"
endevent
```

## Good

```isl
event inq : 1 // ask
  var v : n3
  input v, "Enter value"
endevent
```
