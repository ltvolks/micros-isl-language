# L029: Duplicate variable declaration

| Property | Value |
| --- | --- |
| Severity | error / warning |
| Fixable | no |
| Source | [Command: Var](../../skills/micros-isl-language/isl-reference/reference/commands.md#var), [Error: Duplicate variable def](../../skills/micros-isl-language/isl-reference/reference/errors.md#duplicate-variable-def) |

The same name declared twice in one scope (error), or a local that hides a global (warning).

## Why

ISL reports "Duplicate variable def" for a second declaration of the same name.

## Bad

```isl
event init
  var cnt : n3
  var cnt : n2
endevent
```

## Good

```isl
event init
  var cnt : n3
  var total : n2
endevent
```
