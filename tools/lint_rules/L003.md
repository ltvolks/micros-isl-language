# L003: Wildcard event before specific events

| Property | Value |
| --- | --- |
| Severity | error |
| Fixable | no |
| Source | [Command: Event...EndEvent](../../skills/micros-isl-language/isl-reference/reference/commands.md#eventendevent) |

A `*` event (`Inq : *`, `Tmed : *`, `RxMsg : *`) must come after every specific event of the same type.

## Why

The reference warns that the script text after the `*` event is not read, so specific events written below it are silently ignored.

## Bad

```isl
event inq : *
endevent
event inq : 1 // specific
endevent
```

## Good

```isl
event inq : 1 // specific
endevent
event inq : *
endevent
```
