# L009: Call arguments do not match the sub

| Property | Value |
| --- | --- |
| Severity | error / warning |
| Fixable | no |
| Source | [Command: Sub...EndSub](../../skills/micros-isl-language/isl-reference/reference/commands.md#sub-endsub), [Command: Call](../../skills/micros-isl-language/isl-reference/reference/commands.md#call), [Error: Too few args in call](../../skills/micros-isl-language/isl-reference/reference/errors.md#too-few-args-in-call), [Error: Too many args in call](../../skills/micros-isl-language/isl-reference/reference/errors.md#too-many-args-in-call), [Error: Expected array in call](../../skills/micros-isl-language/isl-reference/reference/errors.md#expected-array-in-call), [Error: Undefined call](../../skills/micros-isl-language/isl-reference/reference/errors.md#undefined-call) |

A `call` passes the wrong number of arguments, gives a literal to a `ref` parameter, passes a plain variable where the sub expects an array (`name[]`), or calls a sub the file does not define (warning).

## Why

ISL checks the argument list against the `sub` line when the call runs and stops with one of the "args in call" errors.

## Bad

```isl
sub s(ref a, var b : n3)
endsub
event init
  call s(1)
endevent
```

## Good

```isl
sub s(ref a, var b : n3)
endsub
event init
  var x : n3
  call s(x, 2)
endevent
```

## Limits

A sub defined in a different script is reported as unknown; the call is only a warning for that reason.
