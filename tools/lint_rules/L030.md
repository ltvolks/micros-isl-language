# L030: Command outside a procedure

| Property | Value |
| --- | --- |
| Severity | error |
| Fixable | no |
| Source | [Error: Command outside procedure](../../skills/micros-isl-language/isl-reference/reference/errors.md#command-outside-procedure) |

A statement at the top of the script, outside any event or sub, other than `var`, `ContinueOnCancel`, `ExitOnCancel`, `Prorate`, `RetainGlobalVar`, `DiscardGlobalVar`, `SetSignOn…`, `Use…Format`, `Use…TimeOuts`, or a setting of an `@` system variable.

## Why

ISL accepts only these commands outside an event or sub.

## Bad

```isl
window 10, 20

event inq : 1 // show
endevent
```

## Good

```isl
event inq : 1 // show
  window 10, 20
endevent
```
