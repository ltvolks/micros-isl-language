# L033: Statement shape

| Property | Value |
| --- | --- |
| Severity | error |
| Fixable | no |
| Source | [Error: Unexpected end of line](../../skills/micros-isl-language/isl-reference/reference/errors.md#unexpected-end-of-line), [Error: Expected operand](../../skills/micros-isl-language/isl-reference/reference/errors.md#expected-operand), [Error: Expected end of line](../../skills/micros-isl-language/isl-reference/reference/errors.md#expected-end-of-line), [Error: Invalid first token](../../skills/micros-isl-language/isl-reference/reference/errors.md#invalid-first-token), [Error: Format needs string](../../skills/micros-isl-language/isl-reference/reference/errors.md#format-needs-string) |

A statement that ends in a comma or operator, text after a command that takes no arguments (`endif x`), a line starting with a character that cannot start a statement (`*waitclear`), or a `format` with no target variable or no `as`.

## Why

These are the parser errors ISL reports when a line is cut short or has extra text.

## Bad

```isl
event init
  display 2, 2,
  format as "x"
endevent
```

## Good

```isl
event init
  var s : a9
  display 2, 2, "x"
  format s as "x"
endevent
```
