# L019: Print session errors

| Property | Value |
| --- | --- |
| Severity | error / warning |
| Fixable | no |
| Source | [Command: StartPrint[WithStatus]...EndPrint[FF/NOFF]](../../skills/micros-isl-language/isl-reference/reference/commands.md#startprintwithstatusendprintffnoff), [Error: Print already started](../../skills/micros-isl-language/isl-reference/reference/errors.md#print-already-started) |

`startprint` while a print session is open (error), or a literal printer object number that is negative (error) or 0 (warning).

## Why

"Only one print session may be active at any one time from the same UWS." Object number -1 raises an ISL error, and 0 is legal but never prints.

## Bad

```isl
event inq : 1 // print
  startprint @chk
  startprint @rcpt
  endprint
  endprint
endevent
```

## Good

```isl
event inq : 1 // print
  startprint @chk
  endprint
  startprint @rcpt
  endprint
endevent
```
