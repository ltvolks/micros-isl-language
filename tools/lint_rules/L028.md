# L028: Variable used but never declared

| Property | Value |
| --- | --- |
| Severity | warning |
| Fixable | no |
| Source | [Guide ch. 4: User Variables](../../skills/micros-isl-language/isl-reference/guide/chapter-4.md#user-variables), [Error: Variable undefined](../../skills/micros-isl-language/isl-reference/reference/errors.md#variable-undefined) |

An assignment or `for` counter naming a variable that is not declared as a global, in the same event or sub, as a sub parameter, or (in a sub) in any event.

## Why

ISL stops with "Variable undefined" when it reaches the statement.

## Bad

```isl
event init
  total = 1
endevent
```

## Good

```isl
event init
  var total : n3
  total = 1
endevent
```

## Limits

Only assignment targets and `for` counters are checked, not every use.
