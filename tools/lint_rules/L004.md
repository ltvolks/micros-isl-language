# L004: Inquire without a description

| Property | Value |
| --- | --- |
| Severity | warning |
| Fixable | no |
| Source | [Style Guide: Inquires](../../README.md#inquires) |

An `event inq : n` line has no trailing `// description`.

## Why

The description is what the editor symbol list shows (`Inq 1 - Foo the Bar`), so a numbered inquire can be found without remembering the numbers.

## Bad

```isl
event inq : 1
endevent
```

## Good

```isl
event inq : 1 // Foo the Bar
endevent
```
