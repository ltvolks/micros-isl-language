# L034: Operator errors

| Property | Value |
| --- | --- |
| Severity | error / warning |
| Fixable | no |
| Source | [Guide ch. 4: Operator Rules](../../skills/micros-isl-language/isl-reference/guide/chapter-4.md#operator-rules), [Error: Divide by zero](../../skills/micros-isl-language/isl-reference/reference/errors.md#divide-by-zero), [Error: No ops on strings](../../skills/micros-isl-language/isl-reference/reference/errors.md#no-ops-on-strings), [Error: Invalid decimal operation](../../skills/micros-isl-language/isl-reference/reference/errors.md#invalid-decimal-operation) |

Division by a literal 0, an arithmetic operator next to a string literal, or `%` on a decimal ($) variable.

## Why

"Only relational operators are allowed between strings", and `%` is not defined on decimals.

## Bad

```isl
event init
  var i : n3
  i = 5 / 0
endevent
```

## Good

```isl
event init
  var i : n3
  i = 5 / 2
endevent
```

## Limits

`%` on decimals is a warning because only declared variables are recognised.
