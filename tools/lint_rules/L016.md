# L016: User input in Event Init or Event Exit

| Property | Value |
| --- | --- |
| Severity | warning |
| Fixable | no |
| Source | [Event: Event Init](../../skills/micros-isl-language/isl-reference/reference/events.md#event-init), [Event: Event Exit](../../skills/micros-isl-language/isl-reference/reference/events.md#event-exit) |

A command that waits for the operator (Input, InputKey, ListInput, DisplayInput, WindowEdit/Input, WaitForClear/Confirm/Enter, GetEnterOrClear) inside `Event Init` or `Event Exit`.

## Why

"No user input is allowed in this event." Both events run while POS operations starts or stops.

## Bad

```isl
event init
  input name, "Name"
endevent
```

## Good

```isl
event inq : 1 // ask
  input name, "Name"
endevent
```

## Limits

Input reached through a `call` is not followed.
