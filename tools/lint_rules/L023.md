# L023: For loop errors

| Property | Value |
| --- | --- |
| Severity | error |
| Fixable | no |
| Source | [Command: For...EndFor](../../skills/micros-isl-language/isl-reference/reference/commands.md#forendfor), [Error: Loop variable constant](../../skills/micros-isl-language/isl-reference/reference/errors.md#loop-variable-constant), [Error: Loop variable not int](../../skills/micros-isl-language/isl-reference/reference/errors.md#loop-variable-not-int) |

A `for` that is not `for counter = start to end [step n]`, a counter that is not a variable or not an integer (`N`), or `step 0`.

## Why

The counter must be a variable and an integer; a decimal or string counter is a run-time error.

## Bad

```isl
event init
  var i : $10
  for i = 1 to 10
  endfor
endevent
```

## Good

```isl
event init
  var i : n3
  for i = 1 to 10 step 2
  endfor
endevent
```
