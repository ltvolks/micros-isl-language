# L032: List and array index errors

| Property | Value |
| --- | --- |
| Severity | error |
| Fixable | no |
| Source | [Guide ch. 4: Using List Arrays and Records](../../skills/micros-isl-language/isl-reference/guide/chapter-4.md#using-list-arrays-and-records), [Error: Array Index Out of Range](../../skills/micros-isl-language/isl-reference/reference/errors.md#array-index-out-of-range), [Error: List value too big](../../skills/micros-isl-language/isl-reference/reference/errors.md#list-value-too-big), [Error: Must have list var](../../skills/micros-isl-language/isl-reference/reference/errors.md#must-have-list-var) |

A literal index outside `1..size` of a declared array, a list `name[]` in `txmsg`/`rxmsg`/`getrxmsg` with no size before it, or a literal list size above the array.

## Why

Array indexes start at 1 and cannot be negative or past the declared size.

## Bad

```isl
event init
  var a[10] : n5
  a[12] = 1
endevent
```

## Good

```isl
event init
  var a[10] : n5
  a[10] = 1
endevent
```
