# L035: Function errors

| Property | Value |
| --- | --- |
| Severity | error / warning |
| Fixable | no |
| Source | [Reference: functions](../../skills/micros-isl-language/isl-reference/reference/functions.md), [Error: Undefined function](../../skills/micros-isl-language/isl-reference/reference/errors.md#undefined-function), [Error: Start position invalid](../../skills/micros-isl-language/isl-reference/reference/errors.md#start-position-invalid), [Error: Length invalid](../../skills/micros-isl-language/isl-reference/reference/errors.md#length-invalid) |

A call to a name that is neither a command nor a known function (warning), a function with the wrong number of arguments, or `Mid` with a literal negative start or length.

## Why

ISL has no user-defined functions; subs are called with `call`. An unknown name followed by `(` is almost always a typo.

## Bad

```isl
event init
  var s : a9
  s = mid("abc", -2, 3)
endevent
```

## Good

```isl
event init
  var s : a9
  s = mid("abc", 1, 2)
endevent
```

## Limits

Argument counts are checked for functions whose syntax is fixed in the reference.
