# L013: Misused line continuation

| Property | Value |
| --- | --- |
| Severity | error |
| Fixable | no |
| Source | [Guide ch. 3: Continuation Lines](../../skills/micros-isl-language/isl-reference/guide/chapter-3.md#script-writing-style) |

A `\` continuation followed by a comment, or a string literal cut by the continuation.

## Why

"Line continuation characters may not be followed by comments or any other commands", and a string cannot be broken across lines. End the first string and start a new one instead.

## Bad

```isl
event init
  txmsg "a", \ // note
    "b"
endevent
```

## Good

```isl
event init
  txmsg "a", \
    "b" // note
endevent
```
