# L012: Whitespace inside a language element

| Property | Value |
| --- | --- |
| Severity | error |
| Fixable | no |
| Source | [Guide ch. 3: Whitespace](../../skills/micros-isl-language/isl-reference/guide/chapter-3.md#whitespace) |

Whitespace that splits one language element: `@ YEAR`, `< >`, `< =`, `> =`, or `/ /`.

## Why

A language element broken by whitespace produces an ISL token error. The Guide lists these cases.

## Bad

```isl
event init
  display 1, 1, @ CKNUM
  if 1 < > 2
  endif
endevent
```

## Good

```isl
event init
  display 1, 1, @CKNUM
  if 1 <> 2
  endif
endevent
```

## Limits

Specifiers split by whitespace (`N 5`) are reported by [L011](L011.md) in declarations.
