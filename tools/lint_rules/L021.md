# L021: SaveRefInfo outside Event Tmed

| Property | Value |
| --- | --- |
| Severity | warning |
| Fixable | no |
| Source | [Command: SaveRefInfo](../../skills/micros-isl-language/isl-reference/reference/commands.md#saverefinfo), [Error: Max ref info](../../skills/micros-isl-language/isl-reference/reference/errors.md#max-ref-info) |

`saverefinfo` in an event other than `Event Tmed` (an `event rxmsg` callback is accepted), or more than 8 SaveRefInfo statements in one event.

## Why

"The SaveRefInfo command will only work with the Event Tmed procedure", and at most 8 reference lines can be saved.

## Bad

```isl
event inq : 1 // note
  saverefinfo "x"
endevent
```

## Good

```isl
event tmed : 1 // note
  saverefinfo "x"
endevent
```

## Limits

Statements inside loops are not counted.
