# L025: Malformed sub or call line

| Property | Value |
| --- | --- |
| Severity | error |
| Fixable | no |
| Source | [Error: Unexpected data after sub](../../skills/micros-isl-language/isl-reference/reference/errors.md#unexpected-data-after-sub), [Error: Unexpected data after call](../../skills/micros-isl-language/isl-reference/reference/errors.md#unexpected-data-after-call) |

Text after a sub name or a call that is not a parameter or argument list (`sub s - 4`, `call s + 3`).

## Why

ISL reports "Unexpected data after sub" / "after call" and stops.

## Bad

```isl
sub s - 4
endsub
```

## Good

```isl
sub s
endsub
```
