# L024: Sub parameter list errors

| Property | Value |
| --- | --- |
| Severity | error |
| Fixable | no |
| Source | [Command: Sub...EndSub](../../skills/micros-isl-language/isl-reference/reference/commands.md#sub-endsub), [Error: No arrays in sub var](../../skills/micros-isl-language/isl-reference/reference/errors.md#no-arrays-in-sub-var), [Error: Sub array ref invalid](../../skills/micros-isl-language/isl-reference/reference/errors.md#sub-array-ref-invalid), [Error: Unexpected data is sub](../../skills/micros-isl-language/isl-reference/reference/errors.md#unexpected-data-is-sub) |

A sub parameter without `var` or `ref`, an array passed by value, an array reference not written `name[]`, or a by-value parameter with no type.

## Why

"Arrays cannot be passed in by value", and "to pass an array, empty brackets must be placed after the array name both in the Sub and the Call commands."

## Bad

```isl
sub s(var list[] : n3, i : n5)
endsub
```

## Good

```isl
sub s(ref list[], var i : n5)
endsub
```
