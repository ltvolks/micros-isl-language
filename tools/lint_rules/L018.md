# L018: Printing outside StartPrint

| Property | Value |
| --- | --- |
| Severity | warning |
| Fixable | no |
| Source | [Command: PrintLine](../../skills/micros-isl-language/isl-reference/reference/commands.md#printline), [Command: LineFeed](../../skills/micros-isl-language/isl-reference/reference/commands.md#linefeed), [Command: ListPrint](../../skills/micros-isl-language/isl-reference/reference/commands.md#listprint), [Error: Print not started](../../skills/micros-isl-language/isl-reference/reference/errors.md#print-not-started) |

`printline`, `linefeed` or `listprint` in an event with no open `startprint`.

## Why

"The printer must be activated using StartPrint" before PrintLine or LineFeed; ListPrint requires StartPrint and EndPrint.

## Bad

```isl
event inq : 1 // print
  printline "x"
endevent
```

## Good

```isl
event inq : 1 // print
  startprint @chk
  printline "x"
  endprint
endevent
```

## Limits

Subs are not checked, because they are often called while a session is open.
