# L006: Duplicate sub, or WaitForRxMsg without handlers

| Property | Value |
| --- | --- |
| Severity | warning / error |
| Fixable | no |
| Source | [Command: Call](../../skills/micros-isl-language/isl-reference/reference/commands.md#call), [Command: WaitForRxMsg](../../skills/micros-isl-language/isl-reference/reference/commands.md#waitforrxmsg) |

Two subs with the same name (error), or `waitforrxmsg` in a script that defines no `event rxmsg` handlers (warning).

## Why

When a sub is called ISL starts searching from the top of the program, so only the first definition is ever used. A reply that no `event rxmsg` handles is dropped.

## Bad

```isl
sub helper
endsub
sub helper
endsub
```

## Good

```isl
sub helper
endsub
sub other
endsub
```
