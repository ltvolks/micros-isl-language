# L027: Prompt text too long

| Property | Value |
| --- | --- |
| Severity | warning |
| Fixable | no |
| Source | [Command: Prompt](../../skills/micros-isl-language/isl-reference/reference/commands.md#prompt), [Command: Input](../../skills/micros-isl-language/isl-reference/reference/commands.md#input) |

The string literals in a `prompt`, `input` or `getenterorclear` add up to more than 38 characters.

## Why

"The combined length of all prompt_expressions must not exceed 38 characters (including spaces); extra characters will be truncated."

## Bad

```isl
event inq : 1 // ask
  prompt "This text is longer than the thirty-eight characters that fit"
endevent
```

## Good

```isl
event inq : 1 // ask
  prompt "Working, please wait"
endevent
```

## Limits

Only literals are counted.
