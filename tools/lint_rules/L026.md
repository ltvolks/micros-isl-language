# L026: Invalid event id

| Property | Value |
| --- | --- |
| Severity | error |
| Fixable | no |
| Source | [Event: Event RxMsg](../../skills/micros-isl-language/isl-reference/reference/events.md#event-rxmsg) |

`event rxmsg : id` where the id does not start with a letter or `_`, or contains anything but letters, digits and `_`.

## Why

"The event_ID must begin with a letter A - Z, a - z, or the underline character."

## Bad

```isl
event rxmsg : 1reply
endevent
```

## Good

```isl
event rxmsg : reply_1
endevent
```
