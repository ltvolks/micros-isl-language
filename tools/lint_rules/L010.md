# L010: Invalid or reserved name

| Property | Value |
| --- | --- |
| Severity | error |
| Fixable | no |
| Source | [Guide ch. 4: Declaring User Variables](../../skills/micros-isl-language/isl-reference/guide/chapter-4.md#guidelines), [Guide ch. 3: Length of Variables](../../skills/micros-isl-language/isl-reference/guide/chapter-3.md#script-writing-style), [Command: Var](../../skills/micros-isl-language/isl-reference/reference/commands.md#var), [Error: Name is a reserved word](../../skills/micros-isl-language/isl-reference/reference/errors.md#name-is-a-reserved-word), [Error: System variable declaration](../../skills/micros-isl-language/isl-reference/reference/errors.md#system-variable-declaration) |

A variable or sub name that does not start with a letter or `_`, contains anything but letters, digits and `_`, is longer than 255 characters, equals a command, or starts with `@`.

## Why

The reference gives the exact rule: a name begins with A-Z, a-z or `_` and may continue with A-Z, a-z, 0-9 and `_`. Reserved words and system variable names cannot be declared.

## Bad

```isl
event init
  var 1st : n3
  var display : n4
  var @chk : n3
endevent
```

## Good

```isl
event init
  var first_item : n3
  var display_row : n4
endevent
```
