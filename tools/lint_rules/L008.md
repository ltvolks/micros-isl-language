# L008: Whitespace and indentation

| Property | Value |
| --- | --- |
| Severity | warning |
| Fixable | yes |
| Source | [Style Guide: Indentation](../../README.md#indentation) |

Tabs, indentation that differs from the formatter, trailing whitespace, more than two blank lines in a row, or no newline at the end of the file.

## Why

Consistent layout makes block structure visible. Every finding is fixed by `isl.py fmt --write` or `isl.py lint --fix`.

## Bad

```isl
event init
x = 1
endevent
```

## Good

```isl
event init
  x = 1
endevent
```
