# L017: Window protocol

| Property | Value |
| --- | --- |
| Severity | error / warning |
| Fixable | no |
| Source | [Command: Window](../../skills/micros-isl-language/isl-reference/reference/commands.md#window), [Command: Display](../../skills/micros-isl-language/isl-reference/reference/commands.md#display), [Command: DisplayInput](../../skills/micros-isl-language/isl-reference/reference/commands.md#displayinput), [Error: Window has not been defined](../../skills/micros-isl-language/isl-reference/reference/errors.md#window-has-not-been-defined), [Error: Window rows out of range](../../skills/micros-isl-language/isl-reference/reference/errors.md#window-rows-out-of-range), [Error: Display column or row out of range](../../skills/micros-isl-language/isl-reference/reference/errors.md#display-column-or-row-out-of-ran) |

Display-type commands before any `Window` in the event, `DisplayInput` with no following `WindowEdit` or `WindowInput`, more than 64 DisplayInput entries, a literal window outside 1-12 rows by 1-78 columns, or a literal `Display` row or column outside the literal window.

## Why

Display commands place text relative to a window, and DisplayInput fields only take input once WindowEdit or WindowInput runs.

## Bad

```isl
event inq : 1 // show
  window 10, 20
  display 11, 1, "x"
endevent
```

## Good

```isl
event inq : 1 // show
  window 10, 20
  display 10, 1, "x"
endevent
```

## Limits

Only literals are compared. After any `call` the checks for a missing window or WindowInput are skipped because the sub may have opened it.
