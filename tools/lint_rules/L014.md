# L014: Sub inside an event, or event inside a sub

| Property | Value |
| --- | --- |
| Severity | error |
| Fixable | no |
| Source | [Command: Sub...EndSub](../../skills/micros-isl-language/isl-reference/reference/commands.md#sub-endsub), [Error: Sub statement in procedure](../../skills/micros-isl-language/isl-reference/reference/errors.md#sub-statement-in-procedure), [Error: Event inside procedure](../../skills/micros-isl-language/isl-reference/reference/errors.md#event-inside-procedure) |

A `sub` declared between `event` and `endevent`, or an `event` between `sub` and `endsub`.

## Why

"Sub commands are not allowed within an Event." Events and subs are top-level procedures; nesting them is reported here instead of as an unclosed block.

## Bad

```isl
event init
  sub helper
  endsub
endevent
```

## Good

```isl
event init
  call helper
endevent
sub helper
endsub
```
