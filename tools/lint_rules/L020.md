# L020: TxMsg without a reply wait

| Property | Value |
| --- | --- |
| Severity | warning |
| Fixable | no |
| Source | [Command: TxMsg](../../skills/micros-isl-language/isl-reference/reference/commands.md#txmsg), [Command: GetRxMsg](../../skills/micros-isl-language/isl-reference/reference/commands.md#getrxmsg) |

`txmsg` not followed by `waitforrxmsg` or `getrxmsg`, or `getrxmsg` with no `txmsg` before it.

## Why

"The TxMsg command must be followed by the WaitForRxMsg or GetRxMsg command", and GetRxMsg is not a stand-alone command.

## Bad

```isl
event inq : 1 // ask
  txmsg "a"
endevent
```

## Good

```isl
event inq : 1 // ask
  txmsg "a"
  waitforrxmsg
endevent
```

## Limits

Both branches of an `if` may send and share one wait that follows `endif`.
