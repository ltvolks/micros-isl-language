# L015: Return in an event

| Property | Value |
| --- | --- |
| Severity | error |
| Fixable | no |
| Source | [Command: Return](../../skills/micros-isl-language/isl-reference/reference/commands.md#return) |

`return` written directly in an event procedure.

## Why

"The Return command is not allowed in an Event procedure." Use `exitcontinue` / `exitcancel`, or let the event reach `endevent`.

## Bad

```isl
event init
  return
endevent
```

## Good

```isl
sub helper
  return
endsub
```
