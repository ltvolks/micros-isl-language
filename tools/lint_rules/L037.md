# L037: Touchscreen displayed with no keys

| Property | Value |
| --- | --- |
| Severity | warning |
| Fixable | no |
| Source | [Command: ClearIslTs](../../skills/micros-isl-language/isl-reference/reference/commands.md#clearislts), [Command: DisplayIslTs](../../skills/micros-isl-language/isl-reference/reference/commands.md#displayislts), [Error: No touchscreen keys defined](../../skills/micros-isl-language/isl-reference/reference/errors.md#no-touchscreen-keys-defined) |

`displayislts` straight after `clearislts` with no `setisltskey` in between.

## Why

Clearing removes every key, so the touchscreen has nothing to display.

## Bad

```isl
event inq : 1 // keys
  clearislts
  displayislts
endevent
```

## Good

```isl
event inq : 1 // keys
  clearislts
  setisltskey 1, 1, 2, 1, 1, @key_clear, "CLEAR"
  displayislts
endevent
```
