# L005: Missing docstring banner

| Property | Value |
| --- | --- |
| Severity | warning |
| Fixable | no |
| Source | [Style Guide: Docstrings](../../README.md#docstrings) |

An event or sub has no `// ****…` banner on the line directly above it.

## Why

The banner block documents what the procedure does and what it expects. It is a house style rather than a language rule, so it is a warning.

## Bad

```isl
sub helper
endsub
```

## Good

```isl
// ***********************************************************************
// helper
// ***********************************************************************
sub helper
endsub
```
