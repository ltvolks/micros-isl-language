# L001: Unknown event, command or malformed event line

| Property | Value |
| --- | --- |
| Severity | error / warning |
| Fixable | no |
| Source | [Event: Event Init](../../skills/micros-isl-language/isl-reference/reference/events.md#event-init), [Error: Unknown command](../../skills/micros-isl-language/isl-reference/reference/errors.md#unknown-command), [Error: Event type must be word](../../skills/micros-isl-language/isl-reference/reference/errors.md#event-type-must-be-word) |

An `event` line names an event the reference does not list (error), `event inq` / `event tmed` has no number or `*`, `event rxmsg` has no message id, or a statement starts with a word that is not a command of the 3700 ISL (warning).

## Why

SIM looks events up by name and type. An unknown event is never executed, and an unknown command stops the script with "Unknown command" at run time. A warning rather than an error is used for commands because 9700-only commands also appear in shared scripts.

## Bad

```isl
event void
endevent

event inq
endevent

event inq : 1 // look up
  frobnicate 1
endevent
```

## Good

```isl
event init
endevent

event inq : 1 // look up
  display 1, 1, "x"
endevent
```

## Limits

The list of commands (`KNOWN_COMMANDS` in `tools/isl.py`) comes from the reference; a command added by a later 3700 release is reported until the list is extended.
